# 🚀 محرك الواتساب الذكي الداخلي (Fastro WhatsApp Engine)

محرك مصغر مفتوح المصدر ومجاني 100% مبني بـ Node.js ومكتبة `@whiskeysockets/baileys`، يتيح للمكاتب المشتركة في نظام الشحن مسح رمز الـ QR Code مباشرة من شاشة النظام (الأجهزة المرتبطة) وإرسال الرسائل التلقائية للعملاء بدون دفع اشتراك شهري لأي وسيط خارجي.

---

## 🌟 المميزات
1. **تعدد المكاتب (Multi-Tenancy):** كل مكتب له جلسة اتصال مستقلة برقم هاتفه الخاص.
2. **مجاني للأبد:** لا توجد أي اشتراكات أو تكاليف رسائل.
3. **أمان تام:** اتصال مباشر ومشفر بين سيرفرك وخوادم واتساب.
4. **توليد QR Code فوري:** إرجاع رمز الـ QR كصورة Base64 لعرضه للمستخدم مباشرة.
5. **استعادة الجلسات تلقائياً:** عند إعادة تشغيل السيرفر يستعيد المحرك أرقام المكاتب المتصلة بدون إعادة مسح الـ QR.

---

## 🛠️ خيارات التشغيل والاستضافة المجانية

### الخيار 1: النشر المجاني على Render.com (أسهل وأسرع خيار مجاناً 100%)
1. أنشئ حساباً مجانياً على [Render.com](https://render.com).
2. اضغط **New +** ⬅️ **Web Service**.
3. قم برفع مجلد `whatsapp-engine` على مستودع GitHub خاص بك، أو اختر النشر المباشر.
4. في إعدادات Render:
   - **Environment:** `Node`
   - **Build Command:** `npm install`
   - **Start Command:** `node server.js`
   - **Plan:** `Free`
5. في قسم **Environment Variables**:
   - أضف مفتاح: `WHATSAPP_ENGINE_SECRET` وضع أي كلمة سر قوية من اختيارك (مثال: `MySecretKey_2026`).
6. اضغط **Create Web Service**.
7. بعد اكتمال البناء، انسخ رابط موقعك (مثال: `https://fastro-whatsapp.onrender.com`) وضعه في لوحة الإدارة العامة لنظام الشحن!

---

### الخيار 2: التشغيل على سيرفر VPS (Ubuntu/Debian)
إذا كان لديك سيرفر خاص أو VPS:
```bash
cd whatsapp-engine
npm install
npm install -g pm2
pm2 start server.js --name "fastro-whatsapp"
pm2 save
pm2 startup
```

---

### الخيار 3: التشغيل المحلي على جهازك للتجربة (Windows / Mac)
```bash
cd whatsapp-engine
npm install
node server.js
```
سيعمل السيرفر على: `http://localhost:3000`

---

## 🔗 الربط مع نظام الشحن (Laravel)
ادخل إلى لوحة الإدارة العامة في السيستم:
**لوحة القيادة ⬅️ محرك الواتساب ⬅️ إعدادات محرك الواتساب السحابي العام**:
- **رابط السيرفر:** `https://your-app.onrender.com` (أو `http://127.0.0.1:3000` محلياً).
- **المفتاح السري:** نفس قيمة `WHATSAPP_ENGINE_SECRET` التي حددتها.

وسيصبح خيار مسح الـ QR متاحاً لجميع المشتركين فوراً!
