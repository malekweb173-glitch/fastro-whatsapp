# 🚀 محرك الواتساب السحابي الذكي (Meta Infinity WhatsApp Engine)

محرك مصغر مفتوح المصدر ومجاني 100% مبني بـ Node.js ومكتبة `@whiskeysockets/baileys`، مصمم خصيصاً لنظام **Meta Infinity ERP** لربط حساب واتساب الأعمال ومسح رمز الـ QR Code مباشرة من شاشة النظام وإرسال الفواتير الرسمية وسندات القبض وإشعارات العملاء وتنبيهات المستشار المالي آلياً ومجاناً مدى الحياة دون أي اشتراكات خارجية.

---

## 🌟 المميزات
1. **مجاني للأبد 100%:** لا توجد رسوم قوالب Meta ولا اشتراكات وسيط خارجي.
2. **استضافة سحابية مجانية:** يعمل على باقة Render.com المجانية بدون الحاجة لسيرفر VPS أو Docker خاص.
3. **دعم إرسال المستندات و PDF:** إرسال الفواتير وسندات القبض كملفات PDF رسمية مباشرة للعملاء عبر واتساب.
4. **توليد QR Code فوري:** إرجاع رمز الـ QR كصورة Base64 لعرضه للمستخدم داخل النظام مباشرة.
5. **استعادة الجلسات تلقائياً:** عند إعادة تشغيل السيرفر يستعيد المحرك رقم الهاتف المتصل دون الحاجة لإعادة مسح الـ QR.

---

## 🛠️ خطوات التشغيل والنشر المجاني على Render.com (في دقيقتين)

1. أنشئ حساباً مجانياً على [Render.com](https://render.com).
2. اضغط **New +** ⬅️ **Web Service**.
3. قم برفع مجلد `whatsapp-engine` على مستودع GitHub خاص بك، أو اختر النشر من المستودع.
4. في إعدادات الخدمة على Render:
   - **Name:** `meta-whatsapp-engine` (أو أي اسم تفضله)
   - **Environment:** `Node`
   - **Build Command:** `npm install`
   - **Start Command:** `node server.js`
   - **Plan:** `Free`
5. في قسم **Environment Variables**:
   - أضف مفتاح: `WHATSAPP_ENGINE_SECRET` وضع كلمة سر قوية للربط (مثال: `meta_secret_2026`).
6. اضغط **Create Web Service**.
7. بعد انتهاء النشر، انسخ الرابط الناتج (مثال: `https://meta-whatsapp-engine.onrender.com`).
8. ادخل إلى نظامك: **مركز واتساب والأتمتة الذكية ⬅️ إعدادات البوابة والربط ⬅️ محرك الواتساب السحابي**:
   - ضع الرابط في **رابط سيرفر محرك الواتساب السحابي**.
   - ضع كلمة السر في **المفتاح السري للربط**.
   - اضغط **فحص السيرفر** ثم **توليد كود الـ QR** وامسحه بهاتفك!
